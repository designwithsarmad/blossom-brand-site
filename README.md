# Bloom & Build

Role & Task: Act as an expert UI/UX designer and frontend developer. I need you to build three responsive, high-converting web pages based on the exact copy, structure, and SEO metadata provided in the attached document ("updated pages.md").

Design System & Aesthetics: First, analyze the live website at https://www.brinsposyfloral.com/ to extract the brand's visual identity. The UI must perfectly match this established aesthetic:

Vibe: Boutique floral, elegant, warm, and inviting.

Color Palette: Utilize earthy, natural tones (e.g., Sage Green for primary accents, Soft Blush/Taupe for secondary elements, and an Off-White/Cream background for warmth).

Typography: Use an elegant, traditional Serif font (like Georgia, Playfair Display, or similar) for all headings (H1, H2, H3) to convey a premium feel. Use a clean, readable Sans-Serif for body text, form fields, and buttons.

Styling: Apply soft shadows, rounded corners on buttons/forms (4px to 8px), and ensure generous whitespace between sections to let the content breathe.

Page-Specific Requirements:

Weddings & Events: Design a striking hero section with trust badges directly below the subheadline. Format the "Wedding Pricing" section as a clean, easy-to-read table or grid. Include a placeholder grid for the 6-9 gallery images.

Everyday & Sympathy Flowers: Emphasize the "Urgent CTA" button above the fold using a distinct highlight color (like a muted red or deep rose) to stand out from standard buttons. Include a well-styled placeholder block for a WooCommerce product.

Get a Quote: Style this long scrollable form cleanly. Group the inputs into distinct visual fieldsets (Contact Info, Wedding Details, Vendor Team, etc.) using subtle borders or background color shifts to prevent user fatigue. Ensure form fields, dropdowns, and radio buttons have clear focus states.

Output: Generate the fully styled, responsive layout for these three pages. Ensure the code/components are modular, accessible, and ready for production.
